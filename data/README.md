# HarborGuard 演示数据

这些文件是位于洛杉矶港区域坐标系内的**人工示意数据**，不是核验过的海图、实际码头边界、航道、浮标部署、资产位置或船期。简化多边形水域和邻接关系用于 24 小时黑客松的算法与接口演示，不能用于航行、实际封港或安全决策。它们没有经过 geojson.io 底图逐点核验；任务书 B2 的真实港区边界和目视水陆核验仍需团队补齐。

- `zones.geojson`：12 个有效多边形，含 6 个泊位区、4 个相连航道段、2 个锚地。邻接图双向；入口能到达所有泊位区。
- `assets.json`：5 个虚构受保护资产，位于对应泊位示意区内。
- `buoys.json`：10 个虚构浮标 B1–B10，全部位于示意水域中。沿路线错开布设，避免连续方位交叉角小于 20° 的定位盲区；泊位附近加密，不是实际 500–800 米等距部署。
- `vessels.json`：40 条固定的虚构船期，时间为场景起点后 0–6 小时。
- `scenarios/scenario_a.yaml`：种子 42；UUV、两个鱼群、三艘合作船舶、一个远处哺乳动物。UUV 先向东航行 410 米，再接近集装箱资产，为风险升级提供演示节奏。
- `scenarios/scenario_b.yaml`：种子 7；4 个海底碎片，B4 与 B7 于仿真第 60 秒失效。南部航路与集装箱泊位可先复航，北部分区保留未勘测状态。

坐标采用任务书冻结的 WGS84 / 本地米制换算，原点 `(33.7300, -118.2600)`。所有船名和资产名称均为虚构，声学、运动与覆盖参数也是演示假设。

`python data/build_demo_data.py` 可重建上述文件，并同步四个 JSON / GeoJSON 到 `frontend/public/data/`。重新生成后运行 `python -m pytest backend/tests/test_data.py backend/tests/test_simulation.py`。生成脚本只处理 B 负责的数据，不创建或修改前端源代码。
