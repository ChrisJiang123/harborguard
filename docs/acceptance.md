# 任务书验收范围

以任务书 B 为主要依据，先交付本地可运行、可测试、接口可对接的 MVP。下列区分代码验证与需要真人、队友代码或外部仓库才能完成的验收。

最终状态以 [集成检查报告](final-integration-report.md) 和 [Demo 操作单](demo-runbook.md) 为准。当前支持受控演示与 Draft 提交；A 的两项缺口由 A 修复，不代表全部验收已完成。

| 步骤 | 已实现的后端能力 | 剩余团队或外部验收 |
| --- | --- | --- |
| B0–B1 | 分支、契约/样例、全部 REST/WS、500 条事件缓存、CORS；主体已由 PR #2 合入 main，A 的真实 LIVE 已验证，交接材料在 Draft #3 | A 刷新/重连未消费事件补偿；最终集成 Draft 待队友审查 |
| B2 | 12 个分区、6 泊位、4 航道、2 锚地、5 资产、10 浮标、40 船期、前端静态副本；A 已显示真实业务图层 | 示意几何尚未按真实海图核验水陆和部署 |
| B3 | 固定种子场景、五类目标、固定子步、WGS84、暂停/恢复/倍速/重置；真实 LIVE 与 3D 渲染已验证 | 演示电脑 GPU 帧率、投影可读性 |
| B4 | 匿名声学测量、正向交会、SNR 一致性排除多船虚假交点、聚类、Kalman、马氏关联、确认/删除、AIS、历史与预测 | 实际声呐或真实海况性能不在本演示验证范围 |
| B5 | 风险/三级/迟滞、禁 ping、识别图、方案比较、人工审批；真实前端批准和模板 Agent 回传已验证 | A 刷新审批记录恢复；训练识别权重不在本轮 Demo 范围 |
| B6 | 灾害复航、故障、回放、建议校验/广播、日志、指标、问答；真实 C 模板 WS/REST 闭环和 A/B 回放末帧已验证 | A 的无航迹碎片识别入口；云端/Ollama/LoRA 不在本轮范围 |
| B7 | 103 项回归通过、2 项权重测试跳过；真实组合 20 项检查；五分钟操作单，指标见 validation.md | 全员彩排、真实断 Wi-Fi、录屏/投影验收；单 tick 20ms 仍有超限 |

后端只提供方案与状态；安防 `restricted` 状态仅由操作员 approve 写入。灾害模式的 `clear`、`blocked`、`unsurveyed` 是模拟调查结果，不触发自动封港。所有降级桩在消息中标明 `model: "stub"`，离线建议标明 `model: "template"`。
