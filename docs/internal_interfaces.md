# Backend module integration

External contract is the taskbook appendix and `shared/contract.md`. Internal dicts below are never sent unchecked.

* `World()` loads data; `start(scenario_id, speed=None)` resets and creates seeded targets. Fields: `t`, `mode`, `network`, `scenario_id`, `paused`, `speed`, `duration_s`, `rng`, `targets` (list), `buoys` (dict id -> contract Buoy dict), `noise_up` (bool). `step(dt)` advances and returns due `(event_name, data)` pairs; failures return `buoy_changed` etc. World does no perception/decision. `reset()` goes idle (`scenario_id=None`, t=0).
* Target fields: `id`, `cls`, `x`, `y`, `depth`, `vx`, `vy`, `vz`, `length_m`, `width_m`; `step(dt,rng)`; `calling(t)` for mammals. Local east/north/depth in meters. `geo.to_local(lat,lon)` and `to_geo(x,y)`.
* `Acoustics.observe(world, dt=1.0)` returns anonymous observations. `localize(observations, buoys)` returns position measurements with covariance and cue. `Tracker.update(measurements,t,targets=[])` scans; `Tracker.predict(dt)` predicts; `Tracker.tracks(t)` returns contract track dicts with full history; `Tracker.set_classification(track_id, cls, conf, detection_id)` persists ping classification. No source target IDs in observations or tracker association; AIS matching may use vessel truth only.
* `DecisionEngine(zones_geojson, assets, vessels)` owns zone states, alert/options/detection caches. `step(tracks, world, dt)` -> list of `(name,data)` events; may update input track dictionaries (risk/level/cls/conf/detection_id). Fields `alerts` dict, `options` dict alert_id -> {alert_id,options,ranked}, `detections` dict, `images` dict det_id -> png bytes, `zone_statuses` dict zone_id -> {id,state,coverage}. `approve(alert_id,option_id,action,operator,t)` returns events; raises ValueError for invalid/stale choices. `set_mode(mode,t)` returns events; security -> open except operator restrictions, disaster -> unsurveyed. `reset(mode='security')` resets all state. `reopen_plan` may be None or contract dict.
* Main integration in `engine.py`: advances world fixed substeps, predicts tracker, scans every simulated second, decision tick, outputs validated models and events. Same engine used live and offline recording. No imports from FastAPI inside numerical modules.
* All modules use `config.py` constants, may add uniquely named parameters there with an append-only edit if needed. Main owns models/API/bus/tools; other agents own only their assigned modules/tests/data. No edits to `ml/`, `agent/`, frontend source. B owns frontend/public/data and replay data as taskbook permits.
